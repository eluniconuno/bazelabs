# Baze Labs

Site pessoal de Emanuel Eidt, artista visual. Digital art research engine by Emanuel Eidt.

Feito com [Astro](https://astro.build) e [Keystatic](https://keystatic.com). Publicado na Netlify.

```
npm install
npm run dev      # site em http://127.0.0.1:4321 e painel em /keystatic
npm run build    # gera o site em dist/
```

Para publicar textos e trabalhos pelo painel, leia o [GUIA-CMS.md](GUIA-CMS.md).
